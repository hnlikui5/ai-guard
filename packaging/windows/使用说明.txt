AI卫士（AI Guard）v0.1.0 — 本地 AI 编程安全防火墙
======================================================

【产品简介】
AI卫士是专为个人开发者设计的本地 AI 编程执行前安全拦截工具。
通过与 Codex 等 Agent 工具执行前（PreToolUse）机制深度集成，在毫秒级内完成
高危命令（高危全盘删除、裸盘格式化、未验证管道执行、凭据窃取等）的检测与阻断。

【核心功能】
1. 双环境协同防护：同时纳管 Windows 宿主机与 WSL2 子系统中的 Codex。
2. 毫秒级规则裁决：内置 6 类高危规则，裁决延迟 < 2ms，日常开发命令零误杀。
3. 历史会话安全备份：支持一键对 AI 会话生成 SHA-256 完备校验的快照归档。
4. 审计与脱敏导出：本地 SQLite WAL 审计流水，敏感 API Key/Token 自动脱敏导出。
5. 零管理员提权：安装与运行均限制在当前用户空间与 127.0.0.1 本地回路。

【使用指南】
- 双击桌面「AI卫士」快捷方式启动控制台。
- 浏览器控制台地址：http://127.0.0.1:17900
- 如需卸载，可在 Windows「设置 -> 应用 -> 已安装的应用」中搜索「AI卫士」点击卸载，或使用开始菜单中的「卸载AI卫士」。
