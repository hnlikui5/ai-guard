# references

第三方开源项目源码参考区。

## 使用规则

1. **只读参考**：本目录下的所有第三方仓库仅用于架构研究、安全规则分析与设计参考，保持只读状态。
2. **禁止参与构建**：本目录下的代码不纳入 AI卫士（AI Guard）的任何编译、打包或运行时依赖。
3. **禁止直接复制**：严禁将本目录下的第三方源码直接复制到 `apps/` 或 `packages/` 业务目录中。
4. **Git 忽略约束**：所有克隆到本目录的第三方仓库均已通过 `.gitignore` 排除（仅保留本 `README.md`），不提交到 AI卫士主仓库。
5. **合规记录**：任何新增参考项目均须在 `docs/REFERENCES.md` 中登记仓库地址、许可证类型、版本号及 Commit Hash。
