# apps/desktop

桌面应用及本地管理界面模块。

## 模块职责

- 提供全中文可视化管理界面
- 展示受管 AI 编程 Agent（首期支持 Codex）的运行状态与连接健康度
- 安全策略配置、高危指令拦截提醒与实时人工审批交互
- Session 历史检索、详情浏览与备份恢复操作入口
- 本地系统设置与环境诊断展示

## 架构约束

- UI 层仅通过 `apps/local-service` 提供的标准本地服务接口进行数据交互与指令下发。
- **严禁**在桌面端 UI 代码中直接读写 Agent 的内部数据文件、Session 原始文件或直接操作底层 SQLite 数据库。
- 考虑 Windows 宿主机桌面端与 WSL2 Ubuntu 内 Agent 环境的跨边界通信适配。
