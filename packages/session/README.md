# packages/session

Session 读取、解析、索引与生命周期管理模块。

## 模块职责

- 安全读取与解析 Agent 会话数据（V0.1 优先支持 Codex Session 数据格式）
- 构建本地会话元数据索引，支持按时间、项目工作区、状态及关键词检索
- 提供会话导出、清理、归档等生命周期管理能力
- 承接原 M1 阶段已验证的 Codex Session 管理核心成果

## 架构约束

- 对 Agent 原始运行目录中的活动 Session 文件坚持**只读优先**原则，避免破坏 Agent 正在写入的上下文状态。
- 涉及修改、清理或恢复操作时，必须联动 `packages/backup` 先执行快照备份与完整性校验。
