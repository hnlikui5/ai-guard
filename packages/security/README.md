# packages/security

安全策略引擎、高危动作拦截、审批流转与审计核心模块。

## 模块职责

- 命令执行、敏感文件读写、危险 Git 操作、环境变量与密钥读取的风险识别与分级
- 安全策略规则匹配与裁决（Allow / Prompt / Deny）
- 人工审批状态机与超时控制
- 面向安全事件的不可篡改本地审计记录生成

## 架构约束

- **默认安全、失败可控（Fail-Closed / Safe Default）**：当策略解析异常、上下文缺失或审批超时，默认采取阻断或最小权限策略，严禁异常默认放行。
- 策略评估逻辑与具体 Agent 的 Hook 实现机制解耦。
- 优先吸收和复用成熟开源安全方案（如 HOL Guard、nono、Pipelock）中经过验证的规则模型与防护思路，但不直接照搬耦合代码。
